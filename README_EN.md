# Part-Aware Hyena Individual Identification

**English** | [简体中文](README.md)

The 5th-place solution to the iFLYTEK Hyena Individual Identification Challenge
（野生鬣狗个体识别挑战赛）, with an online Macro-F1 of **0.77415**. The method
combines part-aware representations, heterogeneous visual backbones, label-free
foreground observations, and part-wise raw-score ensembling.

## Method

- Part-aware DINOv3-H+/16 with global, stripe, and covariance descriptors;
- Heterogeneous DINOv3 ConvNeXt-L and BioCLIP ViT-B/16 models;
- Label-free foreground observations generated by SAM2.1 Hiera-Tiny;
- Generic individual representation transfer from DogFaceNet, excluding its identity head;
- Part-wise non-TTA raw-score ensemble for `head`, `left_body`, and `right_body`.

See the [method description](docs/METHOD.md) for architectures, objectives, and
ensemble equations. The complete recipe is available in
[configs/final_pipeline.yaml](configs/final_pipeline.yaml).

## Reproduction

### Environment

Reference environment: Linux, Python 3.11, CUDA 12.8, PyTorch 2.9.1, and one
RTX 3090 24 GB GPU.

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
make verify
```

### Data Preparation

Download the public competition bundle and the referenced Hyena ID 2022 archive:

- [iFLYTEK Challenge Platform](https://challenge.xfyun.cn/)
- [LILA Hyena ID 2022](https://lila.science/datasets/hyena-id-2022/)
- [Kaggle mirror](https://www.kaggle.com/datasets/ashfaqsyed/hyena-dataset)

```bash
make prepare-data \
  PUBLIC_DATA_ZIP=/path/to/dataset\(public\).zip \
  HYENA_DATA_ZIP=/path/to/hyena-dataset.zip
```

Prepared data is written to `work/competition/`. The external DogFaceNet data comes
from [Zenodo 12578449](https://zenodo.org/records/12578449) under CC BY 4.0; the
main pipeline uses the pretrained generic representation included in the weight bundle.

### Pretrained Weights

> [Baidu Netdisk: download the complete `weights` directory](https://pan.baidu.com/s/15SQ2cEHe5u3Z0TI1WKxdUQ?pwd=gv24)  
> Extraction code: `gv24`

Keep the directory unchanged and place it next to the repository:

```text
workspace/
├── hyena-identification/
└── weights/
```

```bash
make verify-weights
```

### Training

```bash
git clone https://github.com/facebookresearch/sam2.git third_party/sam2
git -C third_party/sam2 checkout 2b90b9f5ceec907a1c18123530e92e794ad901a4
export SAM2_REPO=$PWD/third_party/sam2
make masks
make train
```

The pipeline trains eight models sequentially and takes about 25 hours on one RTX 3090.

### Inference

After each model is trained, `make train` performs one non-TTA test forward pass and
runs the final part-wise ensemble. Outputs:

```text
work/full_run/final_submission/submission.csv
work/full_run/final_submission/submission.zip
work/full_run/final_submission/reproduction_report.json
```
